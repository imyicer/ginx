# GinX

Static snapshot of the public GinX website, captured on 10 October 2026.

Live website: https://imyicer.github.io/ginx/

Market prices and public statistics are frozen. BTCUSD: **83,029.90**.
Trading, login and account entry points lead to the system upgrade notice at `/ginx/upgrade/`.
The original particle animation, styling, public pages, FAQ and language interface are retained.
The support button provides email contact details. Trading, authentication, submissions and third-party online services are disabled in this static snapshot.

## Publishing

GitHub Pages serves the `main` branch from the repository root. `.nojekyll` disables Jekyll processing.
This copy uses the `/ginx/` base path, including resources, React Router and internal links.
To use a different repository name or domain root, regenerate the base-path adaptation before deploying.

This repository contains static deployment files only; no credentials or private account data are included.
